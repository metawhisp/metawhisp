What Jev is
  TypeSafe's "System One" decision model, served through OpenRouter. It returns typed answers with
  probabilities — Choice (one of the options), Noul (yes/no), Score (a place on an ordered scale) — and
  never text, reasoning or explanations.

The wire, as the documentation gives it (field names only; the pages hold the full schema)
  - POST https://openrouter.ai/api/alpha/decisions, "Authorization: Bearer <OpenRouter key>", JSON.
  - Request: model ("typesafe/jev-1.13"; "~typesafe/jev-latest" tracks the newest release), state (an
    object), questions (a map of name → type choice|noul|score, instructions, criteria). All questions in
    one request are answered in parallel and do not see each other's answers.
  - Response: answers per question — choice: choice, probabilities, confidence; noul: the probability of
    yes; score: score, probabilities, confidence, legend — plus usage {input_tokens, output_tokens, cost in
    USD} and model, the dated snapshot that answered.
  - Context: 32,000 tokens for state plus questions. Input tokens are billed; output tokens are free.
  - A second surface, POST https://openrouter.ai/api/v1/systemone, serves the TypeSafe SDKs.
  - No TypeSafe account is needed: the OpenRouter key authenticates and is billed.
