Why: jev-ultrafast sends a step's instructions as an object ({goal, rules} and {goal, operation,
rules: [NEXT_ACTION, TARGET]}) and describes each target as an object. The Pro server passes questions
through as they come (decisionsRequestProblem checks only each question's type), so the one open
point was OpenRouter's alpha decisions endpoint.

Call: POST https://openrouter.ai/api/alpha/decisions, straight to OpenRouter with the owner's
OpenRouter key from the keychain (not printed, not stored). A made-up page; no user data.
Result: HTTP 200 in 0.53 s.
