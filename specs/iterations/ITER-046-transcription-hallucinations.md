## Цель (проверяемая)

Русская и смешанная RU/EN речь не превращается в английский связный бред; в сохранённый транскрипт
митинга не попадают сегменты с метриками галлюцинации; чередование Me/Them соответствует реальному
таймингу речи. Проверка: регрессионные тесты ниже зелёные + ручной прогон 30-мин записи созвона.

## User stories

1. Как RU-пользователь, я диктую по-русски с английскими терминами («линкбилдинг», «слоп») и получаю
   русский текст с корректными терминами, а не EN-бред.
   Приёмка: prompt-слова не инжектятся при не-EN языке ни в одном пути; тест фиксирует гейт.
2. Как пользователь митингов, я получаю транскрипт, где реплики Me/Them чередуются по реальному
   таймингу, а сегменты «из тишины» отфильтрованы по метрикам уверенности.
   Приёмка: таймстампы учитывают trim-офсет; сегменты с плохими метриками дропаются; тесты зелёные.

## Находки (все верифицированы по коду 2026-06-09)

### TR-3 (P1). EN-prompt bias не загейчен везде — главный кандидат на причину репорта
Верифицировано:
- `App/AppDelegate.swift:1421` — meeting chunks: `BrandGlossary.canonicalNames()` (EN-only) безусловно.
- `App/AppDelegate.swift:1616` — dormant live-tail путь: то же самое (чинить заодно).
- `Services/Intelligence/LiveMeetingAdvisor.swift:218` — live-партиалы митинга: тоже безусловно
  (найдено 2026-06-10 при разборе Meeting Copilot) — именно эти партиалы видит копайлот и recap.
- `Services/System/TranscriptionCoordinator.swift:268` — значения correction dictionary в prompt без гейта
  (glossary при этом загейчен строкой 278 — фикс был частичным).
Механизм задокументирован в `TranscriptionLanguageResolver.swift:23–25` (EN initial_prompt → декодер уходит в `<|en|>`).
**Фикс:** гейтить ВСЕ promptWords через `shouldIncludeBrandGlossary(language:)` в трёх местах.
Для correction dictionary: фильтровать значения по скрипту (кириллица проходит всегда) либо гейтить целиком.

### TR-4 (P1). Temperature fallback генерирует «беглый бред» и его результат сохраняется
Верифицировано по WhisperKit 0.31.3 (`.build/checkouts/WhisperKit/Sources/WhisperKit/Core/Configurations.swift:84–104`):
дефолт `temperatureFallbackCount = 5`, шаг 0.2 → ретраи до t=1.0; `TranscribeTask.swift:365` — после
исчерпания fallback'ов берётся ПОСЛЕДНИЙ (высокотемпературный) результат, даже если он не прошёл пороги.
В `WhisperKitEngine.swift:63–75` fallbackCount не ограничен.
**Фикс:** `temperatureFallbackCount: 1`; сегменты, не прошедшие пороги после fallback — дропать (см. TR-5).

### TR-5 (P1). Метрики уверенности выбрасываются — фильтр только по паттерн-листу
Верифицировано:
- Cloud: `CloudWhisperEngine.swift:214–224` — `verbose_json` запрашивается, но `WhisperSegment`
  декодирует только text/start/end; `avg_logprob` / `no_speech_prob` / `compression_ratio` отброшены.
- Local: WhisperKit отдаёт те же метрики per-segment — в `WhisperKitEngine.swift` не читаются.
  Дефолтные пороги (compressionRatio 2.4, logProb −1.0) работают только как триггер fallback,
  НЕ как финальный фильтр (см. TR-4).
Паттерн-лист (`hallucinationPatterns`, `toxicHallucinationTokens`) не ловит семантический бред — текст
из репорта пользователя прошёл бы все текущие фильтры.
**Фикс:** app-level фильтр сегментов в обоих движках: дроп при
`no_speech_prob > 0.5 && avg_logprob < -1.0` или `compression_ratio > 2.4`. Паттерн-лист — второй слой.
Для митингов дроп логировать с текстом (восстановимость).

### TR-6 (P2). Язык при «auto» детектится заново на каждый 5-мин чанк
Верифицировано: `App/AppDelegate.swift:1407` — lang резолвится внутри цикла чанков; при "auto" → nil →
WhisperKit детектит per-chunk → флип-флоп RU/EN в одной записи. Дефолт настройки "ru"
(`AppSettings.swift:9`), так что бьёт только по auto-пользователям — но вместе с TR-3 даёт именно
репортнутый симптом.
**Фикс:** детект один раз на первом озвученном чанке (mic-стрим приоритетно), пин на остальные чанки
обоих стримов.

### TR-7 (P3). Tiny предлагается в онбординге без предупреждения
Верифицировано: `Views/Windows/Onboarding/OnboardingModelPage.swift:94–95`. Tiny для RU —
катастрофический уровень галлюцинаций.
**Фикс:** default large-v3-turbo; предупреждение при выборе Tiny + не-EN язык.

## Новые баги (найдены при верификации)

### TR-8 (P2). Таймстампы utterance игнорируют срезанную ведущую тишину → кривой merge Me/Them
`App/AppDelegate.swift:1396` — `chunk = trimSilenceEdges(rawChunk)` срезает ведущую тишину;
`:1493–1495` — `absStart = chunkStartSec + w.start`, где `w.start` относителен ТРИММЛЕНОГО чанка,
а `chunkStartSec` — позиция сырого чанка. Все utterance чанка сдвигаются раньше на длину среза
(до десятков секунд в тихих чанках) → `DualStreamMerger` чередует Me/Them неверно.
**Фикс:** `trimSilenceEdges` возвращает `(samples, leadOffsetSamples)`;
`absStart = chunkStartSec + leadSec + w.start`.

### TR-9 (P2). Системный звук ресемплится без анти-алиасинга
`Services/Audio/SystemAudioCaptureService.swift:223–235` — 48→16 кГц голой линейной интерполяцией,
без low-pass. Микрофонный путь корректен (AVAudioConverter, `AudioRecordingService.swift:149–191`).
Алиасинг деградирует стрим «Them» → больше галлюцинаций именно на стороне собеседников в созвонах.
**Фикс:** AVAudioConverter (как в mic-пути) или vDSP decimation с FIR low-pass (ratio ровно 3).

### TR-10 (P3). Дрейф сэмплов на границах буферов системного звука
`SystemAudioCaptureService.swift:225` — `outCount = Int(frameCount * ratio)` с трункацией per-buffer,
дробная позиция не переносится между буферами → потеря сэмплов при frameCount, некратном 3 →
рассинхрон mic/system на длинных созвонах (усугубляет TR-8).
**Фикс:** переносить дробную позицию источника между буферами (или закрывается переходом на
AVAudioConverter в TR-9).

### TR-11 (P3). `mix()` — хард-клип, подписанный как soft clip
`Services/Audio/MeetingRecorder.swift:402–406` — `max(-1, min(1, sum))` это хард-клип → искажения,
когда оба стрима громкие. Используется в live-tail пути.
**Фикс:** настоящий soft clip (tanh) или гейн 0.5 на каждый стрим.

### TR-12 (P3). Митинговый путь дропает «галлюцинации» безвозвратно
`App/AppDelegate.swift:1433–1440` — отфильтрованный чанк теряется (только NSLog). Диктовка при этом
сохраняет подозрительный текст в clipboard (`TranscriptionCoordinator.swift:298–311`) — после трёх
false positives 2026-05-01. В митингах та же страховка отсутствует.
**Фикс:** складывать дропнутый текст в метаданные HistoryItem / отдельный suspect-лог.

- Сегмент с реальной короткой репликой «музыка» — не дропается метрик-фильтром (метрики хорошие)
- Cloud-ответ без segments (json вместо verbose_json) — фильтр деградирует мягко, не крашится

## TR-13: prompt-echo — словарь автозамен в initial_prompt (2026-08-07, шипнуто в 1.3.21)

**Репорт юзера:** вставился текст «вот, и дешевле, линкбилдинг, Не наебывай, что и как, Мабуке.,
в, Лиз, пушить, …» — слова, которые он не произносил.

**Диагноз:** не галлюцинация модели, а эхо нашего же промпта. Coordinator собирал ЗНАЧЕНИЯ
corrections.json (27 не-ASCII фраз, включая мусор типа «Не наебывай» и одиночное «в») в
initial_prompt; на тишине/шуме декодер вернул промпт дословно как «речь». Ни один фильтр не
смотрит на сходство вывода с промптом → текст прошёл как валидный (в suspect-log записи нет).
Течь была только в 1 сайте из 4 (диктовка); остальные 3 передавали чистый глоссарий.

**Второй корень:** learn() из ОДНОЙ правки делал вечное глобальное правило — в словаре жили
«на»→«в» (переписывало каждое «на»), «тот»→«который», «лис»→«Лиз», «домен»→«орга»,
«говорит,»→«говорил,».

**Фиксы (причина, не следствие):**
1. `enginePromptWords(language:)` — единственный источник промпта: кураторский глоссарий,
   EN-gate. Все 4 сайта переведены; API без параметра-списка — словарь структурно не может
   вернуться в промпт. Echo-фильтр на выходе НЕ добавлен сознательно (компенсация следствия).
2. `learn()` — порог 2 одинаковых правки: 1-я = кандидат (persist в corrections-pending.json),
   2-я активирует. Конфликт значений сбрасывает счёт. Ручной `add()` — без порога.
3. 5 отравленных правил удалены из corrections.json юзера (бэкап corrections.backup-2026-08-06).

**Тесты:** +7 (5 learn-threshold через новый seam `init(directory:)`, 2 enginePromptWords),
suite 693 green. Коммиты 57e7ba3 + bump.
