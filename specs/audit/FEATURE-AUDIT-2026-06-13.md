# MetaWhisp 1.3.12 — аудит работоспособности (Free + все фичи)

Дата: 2026-06-13. Метод: разбор кода (gating + фич-поверхность) + частичный Codex-проход (широкий скоуп не уложился в лимит; верификация отдельным узким проходом). Confidence помечен по пунктам.

## Модель Free / BYOK / Pro (ядро) — Confirmed

- **Транскрипция** (`TranscriptionCoordinator` + `transcriptionEngine`):
  - **WhisperKit** — на устройстве, бесплатно, нужна скачанная модель.
  - **CloudWhisperEngine** — если `isPro` + ключ лицензии → **прокси** (Pro, без ключа); иначе → **BYOK** (свой ключ OpenAI/Groq).
- **LLM-фичи** (память, задачи, чат, копайлот, сводки, инсайты): `hasLLMAccess = свой API-ключ ≠ пусто **ИЛИ** isPro **ИЛИ** локальная LLM готова` (`MemoryExtractor.swift:541` и аналоги).

**5 конфигураций пользователя:**
- **A. Free, ничего не настроено** — ни модели, ни ключа.
- **B. Free + локальная модель Whisper** скачана.
- **C. Free + свой API-ключ** (BYOK).
- **D. Free + локальная LLM (Phi)** загружена (тяжёлая, **выкл по умолчанию**).
- **E. Pro.**

`*` D даёт LLM, но для транскрипции всё равно нужна модель Whisper или ключ. `**` Obsidian/MCP технически работают, но экспортировать/отдавать нечего без данных. `¹` **Codex-правка:** `ChatService.hasLLMAccess` (`:1777`), в отличие от остальных, **НЕ включает локальную LLM** — MetaChat работает только при своём ключе или Pro, на локальной LLM (конфиг D) — нет. Асимметрия; либо баг, либо намеренно (локальная модель слаба для tool-calling).

**Вывод по Free:** Free — **полноценное приложение**, но в двух «комплектациях»:
- **B (локальная модель)** = приватная диктовка и транскрипция созвонов на устройстве, **но без «второго мозга»** (память/задачи/чат/сводки требуют LLM).
- **C (свой ключ)** = **всё работает**, пользователь платит за свой API напрямую.
- **A (пусто)** = приложение почти ничего не делает — но это закрыто онбордингом (FREE-1/2: нельзя завершить настройку без рабочего движка).

## Сломанное / мёртвое / требует внимания

1. **Pro-leak (Confirmed, mitigated-but-dormant).** Кэшированный/подложенный ключ в Keychain → `isPro=true` локально → локальный Pro-UI и авто-переключение на облако разблокируются офлайн. Прокси валидирует ключ server-side, так что реального доступа к платному API нет, но клиент «верит». Защита (LIC-1 TTL-гард) **есть, но выключена по умолчанию** (`enforceProEntitlementTTL=false`). — Codex это подтвердил.
2. **Weekly Patterns без UI (Likely, AUD-037/SB-6 — не сделано).** Недельные паттерны генерируются (`WeeklyPatternDetector`), но отдельного экрана для чтения `PatternDigest` нет → результат фактически невидим. Выкл по умолчанию.
3. **Часть тумблеров требует рестарта (Likely, AUD-036/SB-8 — не сделано).** Включение некоторых фич (индексер/шедулеры) применяется только после перезапуска приложения.
4. **`AnimationTestView` — мёртвый dev-экран (Confirmed by Codex).** Инстанцируется только внутри себя (`AnimationTestView.swift:349`), из релизного UI недостижим (тест-allowlist прямо помечает «dead dev-only»). Можно удалить.
6. **`InsightsView` целиком недостижим (Confirmed by Codex — НОВОЕ).** В сайдбаре нет вкладки `.insights` (`MainWindowView.swift:38`), `detailContent` его не рендерит (`:245`). То есть весь экран «Инсайты» в релизе **не открыть**. Вдобавок текст в настройках «Insights tab → GENERATE WEEKLY DIGEST» (`MainSettingsView.swift:2053`) **устарел/сломан** — ссылается на несуществующую вкладку. Вместе с п.2 это значит: инсайты и недельные паттерны генерируются, но **смотреть их негде**.
5. **AI-фичи молча не работают без LLM (Confirmed, UX-разрыв).** В конфиге B (локальная модель, без ключа) задачи/память/чат/сводки просто ничего не делают — без явного сообщения «нужен ключ или Pro». Tasks **включены по умолчанию**, но без LLM не извлекают. Это главный незаметный разрыв для нового free-юзера.

## Дефолты тумблеров (важно для «из коробки»)
ON по умолчанию: Tasks, **Daily Summary** (Codex: AppSettings:231), screen-extraction, meeting-recap-popup, sound.
OFF по умолчанию: memories, weekly, insights, advice, meeting-recording, live-copilot, screen-context, file-indexing, apple-notes, calendar, proactive, realtime-reaction, local-LLM, TTS.
→ Свежий пользователь получает диктовку + (если включит) транскрипцию созвонов; «второй мозг» он **включает сам** и для него нужен LLM-доступ.

## Самый большой разрыв для нового free-юзера
Онбординг теперь гарантирует **рабочую транскрипцию** (модель или ключ). Но если выбрана **локальная модель без LLM-ключа**, весь слой «второго мозга» (память/задачи/чат/сводки) тихо не работает — пользователь не понимает, что для умных фич нужен ключ или Pro. **Рекомендация:** на экранах Tasks/Memories/Chat при `!hasLLMAccess` показывать явный баннер «Для умных функций добавьте API-ключ или включите Pro».

## Безопасность ключей/лицензии — Confirmed OK
Токены/ключи только в Keychain (SEC-1), в URL/логи не попадают (`LicenseService.swift:73` — комментарий-инвариант, токен в Authorization-заголовке, не в query). Plaintext-fallback удалён.
