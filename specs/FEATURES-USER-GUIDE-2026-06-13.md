# MetaWhisp — что умеет приложение (человеческим языком)

Версия 1.3.12 · обзор для пользователя. «Бесплатно/Pro» — внизу каждого блока.

MetaWhisp живёт в меню-баре. Коротко: **ты говоришь — оно превращает речь в текст и в умную память о твоей работе.** Три больших слоя: (1) диктовка, (2) созвоны, (3) «второй мозг» поверх всего этого.

---

## 1. Диктовка (главное)

- Зажми **Right ⌘** (или режим toggle) → говори → текст **вставляется прямо в то приложение, где курсор** (почта, чат, заметки, код — куда угодно).
- Работает на **русском и смешанной речи** (русский с английскими терминами — «линкбилдинг», «слоп» — остаётся как надо, без превращения в английский).
- **Right ⌥** — продиктовать и сразу **перевести** на выбранный язык.
- **Словарь замен** (вкладка Dictionary) — свои бренды/термины/сниппеты, которые всегда пишутся правильно.
- Звук-подтверждение начала/конца (можно выключить).

**Где транскрибируется:** либо **локально на твоём Mac** (скачиваешь модель Whisper — приватно, бесплатно, без интернета), либо **в облаке** (своим ключом OpenAI/Groq, или через Pro без ключа).

**Бесплатно:** да — с локальной моделью (приватно) или со своим API-ключом.

---

## 2. Созвоны и митинги

- **Авто-определение звонка**: Zoom, Meet, Teams, FaceTime, Webex, Slack-huddle, Discord и звонки в браузере — приложение замечает и предлагает записать.
- **Запись созвона** с разделением дорожек: **твой микрофон** и **звук собеседников** пишутся отдельно и сводятся в транскрипт, где реплики «вы / собеседник» идут по реальному времени.
- **Живой Copilot** (overlay во время звонка): подсказки по ходу разговора (что ответить, на что обратить внимание). Опционально.
- **Recap** — после звонка краткое саммари: о чём договорились, решения, задачи, следующие шаги.
- Из созвона **автоматически вытаскиваются задачи и заметки** (см. «Второй мозг»).

**Бесплатно:** транскрипция — да (локально или своим ключом). Copilot/Recap/извлечение — нужен доступ к LLM (локальная LLM, свой ключ, или Pro).

**По умолчанию:** запись созвонов и живой Copilot — **выключены**, включаются в настройках.

---

## 3. «Второй мозг» — память о твоей работе

Из диктовок и созвонов MetaWhisp сам строит структурированную память. Всё видно во вкладках **Library / Tasks / Goals / Projects**.

- **Заметки (Memories)** — факты о тебе и твоей работе (люди, проекты, решения, предпочтения), извлечённые из речи. Чат потом использует их для контекста.
- **Задачи (Tasks)** — экшен-айтемы из разговоров («отправить драфт Майе»). Можно отмечать выполненными/убирать, в т.ч. голосом или через чат.
- **Цели (Goals)** — личные цели с прогрессом.
- **Дневная сводка (Daily Summary)** — что узнал/решил/сделал за день, в карусели на Dashboard.
- **Недельные паттерны** — закономерности за неделю.
- **Инсайты** — наблюдения о работе/привычках.
- **Разговоры и история (Conversations / History)** — все транскрипты, сгруппированные по разговорам и проектам.
- **Проекты** — автогруппировка заметок/задач/созвонов по проектам.

**Бесплатно:** да, если есть доступ к LLM (локальная LLM / свой ключ / Pro). Без LLM — извлечение не работает, но сами транскрипты и история сохраняются.

**По умолчанию:** Tasks — **включены**; Memories, Daily/Weekly, Insights, Advice — **выключены** (включаешь по желанию).

---

## 4. MetaChat — чат с твоей памятью

- Чат, который **знает всё, что ты надиктовал**: заметки, задачи, транскрипты, экранный контекст.
- Может не только отвечать, но и **выполнять действия**: создать/закрыть/убрать задачу, сохранить/забыть заметку, обновить прогресс цели — с кнопкой Undo.

**Бесплатно:** да, при наличии доступа к LLM (свой ключ / локальная LLM / Pro).

---

## 5. Интеграции

- **Obsidian-синхронизация** — всё (заметки, задачи, созвоны, дневные сводки) экспортируется в твой Obsidian-vault с граф-связями (заметка ↔ разговор ↔ проект). Двусторонне: удалил/закрыл — файл в vault тоже убирается.
- **MCP-сервер** — твой «второй мозг» доступен Claude Desktop / Cursor как источник контекста (через MCP).
- **Календарь** — подтягивает встречи, чтобы правильно называть участников в задачах.
- **Apple Notes** — чтение заметок как источника контекста (опционально).
- **Screen Context / Rewind / Files** — OCR активного окна для контекста (опционально, приватность настраивается чёрным/белым списком приложений); история экрана (Rewind); индексация локальных файлов для поиска (RAG).

**Бесплатно:** Obsidian, MCP, календарь — да. Экранные/файловые фичи завязаны на LLM-доступ. Большинство **выключены по умолчанию**.

## 6. Бесплатно vs Pro — коротко

| | Free | Pro ($7.77/мес) |
|---|---|---|
| Диктовка локально (на устройстве, приватно) | ✅ скачай модель | ✅ |
| Диктовка/AI в облаке | ✅ **своим** API-ключом (OpenAI/Groq) | ✅ **без ключа**, через прокси |
| Все AI-фичи (память, чат, созвоны, сводки) | ✅ если есть локальная LLM или свой ключ | ✅ из коробки |
| Настройка ключей | нужно самому | не нужно |
| RAM | локальная модель ест память | облако, модель не грузится |

**Суть:** Free — полностью рабочее приложение, если ты готов либо скачать локальную модель, либо вписать свой API-ключ. Pro — это «не возись с ключами и моделями, всё работает сразу через облако».
