Shrek pill — animated avatar variant

New pill option. Center is a dancing Shrek (animated GIF / video frames). Color and dance speed bind to recording stage. Click a state below to preview. Drop your dancing-Shrek GIF at mockups/shrek-pill.gif — the avatar slot picks it up automatically.

Stage → animation map (per user spec)

  • Recording — Shrek dances at 1.0×, full color.
  • Transcribing — slows to 0.4×, fades to red over 800 ms.
  • Answered / done — speeds back up to 2.0×, color back to normal.
  • Idle (added) — desaturated, slow gentle wobble, lets user know which app the pill belongs to.

Implementation notes (Swift port)

  • HTML <img> can't change GIF playback speed — speed in this mockup is faked via CSS keyframe wobble. In SwiftUI, swap to AVPlayer on a .mp4/.webm conversion of the GIF — set player.rate = 0.4 / 1.0 / 2.0 per stage. Smooth, frame-accurate.
  • Color transition: filter here is CSS. Swift port: .colorMultiply(...) or CIFilter.colorMonochrome with animatable red intensity. 800 ms .easeInOut matches the CSS curve.
  • Pill chrome (capsule, specular rim, glass-flat backdrop, shadow) reuses existing MW.bg / rim-inner / shadow-raised tokens — no new design system work needed.
  • Add as 5th option in AppSettings.pillStyle: "capsule" | "dotglow" | "island" | "glow" | "shrek". Picker lives in Settings → Appearance.
